# Пользовательские модели

## Пользовательские группы и основания для выделения

Рабочие персоны этапа исследования — первокурсница Лера, студент второго курса Илья, студентка по обмену Мина и координатор Ольга.

## Контекст, цели и барьеры каждой группы

Лера ищет актуальную аудиторию, Илья — способ отследить обращение с телефона, Мина — порядок получения справки. Ольге нужен контекст совпадающих занятий.

## Типичные сценарии

Открыть перенос, отправить обращение о конфликте, проверить статус справки.

## Связь с результатами интервью

Персоны использовались для проектирования. Подтверждённых результатов интервью в материалах нет.
