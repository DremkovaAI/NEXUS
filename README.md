# NEXUS — цифровой деканат

Конкурсный прототип цифрового деканата с кабинетами студента и преподавателя. Интерфейс и демонстрационные данные работают в браузере.

## Запуск

Выполните из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory APP
```

Откройте [http://localhost:8000](http://localhost:8000). Для входа используйте выданные командой данные демонстрационного аккаунта. Изменения сохраняются в браузере. Для размещения на хостинге используйте HTTPS, чтобы браузер предоставлял Web Crypto API.
