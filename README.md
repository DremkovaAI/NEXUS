# NEXUS — цифровой деканат

Конкурсный прототип личного кабинета студента и преподавателя на вымышленных учебных данных.

[Открыть прототип](https://nexus-campus-theta.vercel.app/)

## Исходники

- [APP/index.html](APP/index.html) — разметка главной страницы и кабинета.
- [APP/styles.css](APP/styles.css) — стили и мобильная адаптация.
- [APP/app.js](APP/app.js) — сценарии, демонстрационные данные и браузерное хранение.
- [APP/assets/](APP/assets/) — панорамы кампуса, собственный знак NEXUS и иллюстрации интерфейса.
- [AI_CONTEXT/](AI_CONTEXT/) — контекст для ИИ-ассистентов и журнал решений по прототипу.

Панорамы и иллюстрации подготовлены для проекта с помощью генерации изображений в ChatGPT по референсам команды. В интерфейсе используются системные шрифты. На сайте стоит знак NEXUS.

## Локальный запуск

Из корня репозитория запустите:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory APP
```

Откройте [http://localhost:8000](http://localhost:8000). Для входа используйте данные демоаккаунтов из комментария к конкурсной работе. При размещении на хостинге используйте HTTPS для Web Crypto.

Демонстрационные изменения сохраняются в текущем браузере. Вход открывает зашифрованные данные соответствующего аккаунта. Общие записи журнала и переписки хранятся локально и фильтруются приложением по роли и владельцу. Для эксплуатации с реальными данными потребуются серверное хранение и проверка прав.
